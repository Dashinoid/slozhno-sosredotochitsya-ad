# Сложно сосредоточиться

Адаптивная проектная работа Яндекс Практикума с дневной, неоновой и автоматической темами.

Репозиторий: https://github.com/Dashinoid/slozhno-sosredotochitsya-ad

Макет: https://www.figma.com/design/qhgelUhPHUbJVf3jgZsaD7/

## Запуск

Откройте `index.html` в браузере. Сборка, установка пакетов и подключение к серверу не нужны. Изображения и шрифты находятся в проекте и работают без интернета.

## Реализация

- Mobile first, CSS Grid и адаптация от 375 px, с перестроением на 768 и 1024 px.
- Кнопки «День», «Авто», «Неон»; выбор сохраняется штатным скриптом в localStorage.
- В автоматическом режиме используется системная настройка prefers-color-scheme.
- Фиксированный фон, декоративные уголки, адаптивная галерея с ленивой загрузкой.
- Клавиатурный фокус для кнопок и ссылок, описания изображений.

## Структура

- `index.html` — семантическая разметка.
- `styles/variables.css` — исходные CSS-переменные.
- `styles/style.css` — оформление и адаптивная сетка.
- `styles/dark.css`, `styles/light.css` — переопределения цветовых тем.
- `styles/globals.css` — глобальные сбросы.
- `scripts/script.js` — исходный переключатель тем Практикума.
- `fonts/`, `images/` — локальные ресурсы.
